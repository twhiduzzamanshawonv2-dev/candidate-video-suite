Setup guide

Connect your Google Sheet

One time only. Everyone reviewing uses the same link.

  1. Create a new empty Google Sheet. It becomes the list of exams.
  2. Open Extensions → Apps Script, paste the script, and set SECRET to a long random text. Save.
  3. Choose the function setup, press Run, and allow the permissions.
  4. Deploy → New deployment → Web app. Execute as Me, access Anyone. Copy the URL.
  5. Paste the URL above, add ?key= and your secret at the end, then press Connect.
